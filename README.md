# 坐标 → 高德收藏点转换

[English](README.en.md)

一个纯前端的静态网页工具，用于把两步路导出的 GCJ-02 坐标批量转换为高德地图收藏点，并支持逆地理编码、KML / CSV 导出以及高德 URI 链接复制。

## 使用方式

1. 克隆或下载本仓库。
2. 直接用浏览器打开 `amap.html`。
3. 在页面顶部填入你的高德 JS API Key（仅保存在浏览器本地 `localStorage` 中，点击「清除」可删除；悬停「如何获取 Key？」可查看获取步骤）。
4. 在左侧粘贴坐标，每行一个，格式：`纬度,经度` 或 `经度,纬度`，后面可跟名称。

示例：

```text
33.672416, 103.490997
39.908823, 116.397470 天安门
```

## 获取高德 JS API Key

- 直接打开高德控制台[「应用管理」页面](https://console.amap.com/dev/key/app)。
- 注册/登录后点击「创建新应用」，然后在应用上点「添加 Key」。
- 服务平台选择「Web 端 (JS API)」即可获取 Key。

Key 输入后仅保存在你的浏览器本地，不会上传到任何服务器或仓库。

## 功能

- 自动识别经纬度顺序（若第一个数值大于 90，则视为经度在前）。
- 支持 WGS84（默认）/ GCJ-02 / BD09 三种坐标系，解析时自动转换为高德 GCJ-02。
- 在地图上标注所有点位。
- 批量逆地理编码获取地址名称。
- 导出 KML（可在 Google Earth 等软件中打开）。
- 导出 CSV。
- 复制全部高德 URI 链接。
